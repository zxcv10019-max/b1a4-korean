# BANA Forest 透明電腦版 0.2.6

卡片使用較明顯的綠色／米色底色，巢狀卡片也保留原本分區；框線為2px、90%不透明度。每張卡片底色為15%，文字30%；底色重疊處會比單層稍深。

0.2.6：透明效果改為增量更新，避免捲動、輸入或動畫時反覆掃描整頁；修正瀏覽器回傳Google登入時，來源欄位為空值而被拒絕的問題。

解壓縮完整資料夾後，雙擊其中的 `BANA-Forest-Desktop.exe`。請保留同資料夾的其他檔案。

台灣時間週一至週五08:30–18:00：外框與整頁背景完全透明、卡片底色15%、文字30%。其餘時間恢復正常。上方「⠿ 移動」可拖曳；◐ 切換清楚／自動，−最小化，×關閉。右下角圖示可調整視窗大小、重新載入或結束。

網站與電腦版登入相同的 Google 帳號，即可沿用既有雲端同步，不必反覆匯出匯入。首次請先確認原網站已登入並完成同步，再在電腦版按 Google 登入：系統會打開一般瀏覽器，按「Google 登入並連接電腦版」完成授權後回到電腦版查看同步狀態。未登入或離線的資料仍保留於各裝置本機。網站功能更新會在重新載入後生效，無須每次下載電腦版。
