# BANA Forest 電腦版 0.2.8

工具列保留上方40px，固定閱讀視窗、標題和彈出視窗會排在工具列下方，避免遮住返回按鈕或內容。

雙擊資料夾中的 BANA-Forest-Desktop.exe。請保留 runtime 資料夾。

- 預設100%不透明度，保留網站原本的文字、卡片顏色和框線。取消上班時段自動淡化。
- 上方滑桿可即時調整整個視窗的不透明度（10%～100%），調整後會記住。右下角BANA圖示也能恢復100%。
- 「自動藏」：可開關滑鼠移出時隱藏主體，滑鼠移回工具列會展開。拖曳滑桿或選取文字時不會突然收合。
- 「釘」可切換置頂；▴／▾可手動收合／展開。收合後仍可調透明度、拖曳和置頂。
- 網站與電腦版使用同一Google帳號沿用現有雲端同步。登入會交由一般瀏覽器完成。
- 網站內容更新後重新載入即可，不必每次重新下載電腦版。

這是未經正式發行者簽章的自製程式，下載或執行時仍可能出現安全提示。
